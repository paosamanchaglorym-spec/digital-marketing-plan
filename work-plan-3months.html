เว็บ Hiracer
แคตตาล็อก
  • ถอดโครงสร้าง + ดีไซน์
  • ทำหน้าแรก + แคตตาล็อกสินค้าหลัก

  • ปรับความเร็ว + SEO on-page
  • Go live
  • ปรับจูนหลัง live
  • ติดตามคลิกไปช่องทางขาย (conversion)
เว็บ Delta
แคตตาล็อก + ย้าย HK
  • ถอดโครง HK → ร่างโครงเว็บ Delta
  • เริ่มหน้าแรก + วางแผน redirect
  • ทำเว็บครบ + ย้ายบทความ HK + ปุ่ม LINE/Shopee/Lazada
  • ตั้ง 301 redirect (hkmotorguide.com → Delta)
  • Search Console Change of Address
  • Go live + เฝ้าดูอันดับ/ทราฟฟิก
  • ไล่แก้ 404 / ปรับ SEO
เว็บ EDEN
เร่งด่วน
  • ตรวจ/แก้ปัญหาเร่งด่วน + ดันความเร็ว/SEO
  • ปรับปรุงต่อเนื่อง + ใส่ปุ่มช่องทางขาย
  • เฝ้าดูผล
Tracking & วัดผล
  • ติดตั้ง/ตรวจ GTM · GA4 · Pixel ทุกเว็บหลัก
  • Setup CPAS (Shopee/Lazada)
  • วางระบบ UTM + Promo code แยกกลุ่ม
  • Setup Custom Audience / Lookalike
  • ตรวจความแม่นยำข้อมูล (คลาดเคลื่อน <5%)
  • ปรับ audience ตามผลจริง
  • สรุปความแม่นยำระบบวัดผล
SEO & ความเร็วเว็บ
  • PageSpeed baseline ทุกเว็บ ✔ (Mobile ต่ำกว่า 75 ทุกตัว)
  • แก้เว็บวิกฤตก่อน: Mega Play (2) / Avatar (34)
  • Technical + On-page SEO 5–10 หน้าหลัก
  • ไล่ broken links = 0%
  • PageSpeed mobile ให้ถึง 75–80+
  • ขยาย SEO หมวดสินค้าถัดไป
  • วัด Organic Traffic +15%
ยิงแอด & Optimize
  • รีวิวแคมเปญปัจจุบัน หาจุด optimize
  • เริ่ม A/B test ชุดแรก
  • A/B test ต่อเนื่อง (สื่อ + กลุ่มเป้าหมาย)
  • โยกงบจากตัวไม่เวิร์ก → ตัวที่เวิร์ก
  • Scale ตัวที่คุ้ม
  • วัดผล CPA/CPL ลดลง 15%
รายงาน (ประจำ) ทำรายงานรายเดือน (Ad spend, ROAS, CPA/CPC, Traffic, Conversion, PageSpeed, Tracking) เสนอผู้บริหารทุกสิ้นเดือน

เป้าหมาย 3 เดือน (สิ่งที่จะส่งมอบ)

  • เว็บใหม่แบบแคตตาล็อก 2 เว็บ: Hiracer + Delta (Delta = รีแบรนด์ HK + redirect รักษา SEO) · ขายผ่าน LINE/Shopee/Lazada + แก้เว็บ EDEN เร่งด่วน
  • ระบบวัดผลครบ: GTM/GA4/Pixel ทุกเว็บ · event คลิกช่องทางขาย · CPAS Shopee/Lazada · UTM + Promo code 100%
  • เว็บเร็วขึ้น + SEO: PageSpeed mobile 75–80+ · SEO 5–10 หน้า · broken links 0% · Organic +15%
  • แอดคุ้มขึ้น: CPA / CPL ลดลง 15% ด้วย A/B test + Custom/Lookalike audience
  • รายงานรายเดือน เสนอผู้บริหารสม่ำเสมอทุกเดือน
